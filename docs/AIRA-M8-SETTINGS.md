# AIRA M8 — Settings and Privacy Controls

## Implemented
- Persist the user's voice-output preference.
- Review and share chat history through Android's share sheet.
- Clear chat history separately from user-approved memories.
- Provide direct access to memory and model management.
- Explain local storage and microphone/OCR behavior.

## Privacy boundaries
- Sharing is an explicit user action.
- Clearing chat history does not clear saved memories; these are separate controls.
- Voice output preference is stored locally.
