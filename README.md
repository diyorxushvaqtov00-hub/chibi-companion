# Chibi Companion — Malika

Android uchun Kotlin asosidagi suzuvchi chibi yordamchi.

## Hozirgi imkoniyatlar
- Telefon ekranining ustida yuradigan Malika belgisi.
- Belgini barmoq bilan sudrab ko‘chirish.
- Belgiga bosganda suhbat oynasini ochish.
- O‘zbek tilidagi oddiy offline demo suhbat.
- GitHub Actions orqali APK yig‘ish.

## APK olish
1. GitHub’dagi **Actions** bo‘limini oching: https://github.com/diyorxushvaqtov00-hub/chibi-companion/actions
2. Eng so‘nggi **Build Android APK** jarayonini tanlang.
3. Jarayon muvaffaqiyatli tugasa, sahifaning pastidagi **Artifacts** qismidan `chibi-companion-apk` ni yuklab oling.
4. ZIP ichidagi `app-debug.apk` faylini telefonda ochib o‘rnating.
5. Ilovani oching, ekran ustida ko‘rinish ruxsatini bering va yordamchini ishga tushiring.

## Muhim
Suhbat hozircha haqiqiy sun’iy intellekt emas: u internet/API ishlatmaydigan demo javoblardan foydalanadi. Haqiqiy AI uchun keyinchalik maxfiy kalitni APK ichiga joylamaydigan xavfsiz ulanish qo‘shish kerak. Hozircha asl anime personaj rasmlari va animatsiyalari ham kiritilmagan.
